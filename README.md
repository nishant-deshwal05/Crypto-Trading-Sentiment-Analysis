# Crypto-Trading-Sentiment-Analysis
Data analysis project exploring the relationship between crypto trader profitability and market sentiment using the Fear &amp; Greed Index.
# Trader Sentiment Analysis

This project focuses on analyzing trader sentiment and market behavior using Python.

## Technologies Used
- Python
- Pandas
- Matplotlib
- Seaborn
- Jupyter Notebook

## Features
- Data Cleaning
- Exploratory Data Analysis (EDA)
- Sentiment Trend Analysis
- Data Visualization
- Market Behavior Insights

## Objective
To understand trader sentiment patterns and extract meaningful insights from market-related data.
